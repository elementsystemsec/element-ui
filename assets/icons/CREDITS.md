# Iconos

- Logotipos de marcas (`whatsapp`, `instagram`, `facebook`, `tiktok`, `github`, `youtube`, `x`, `gmail`, `html5`, `css`, `javascript`, `php`, `mysql`, `n8n`, `moodle`, `figma`, `react`, `nodedotjs`, `wordpress`, `tailwindcss`, `git`, `python`, `laravel`): [Simple Icons](https://simpleicons.org/), licencia CC0. Las marcas pertenecen a sus dueños; úsalas solo para enlazar o indicar que usas esa tecnología.
- `linkedin`, `correo` y los iconos `srv-*`: dibujos de línea propios de Element UI (MIT).
- `cliente-*`: monogramas de empresas ficticias para los ejemplos. Sustitúyelos por logotipos reales solo con permiso del cliente.
